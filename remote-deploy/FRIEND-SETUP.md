# LED Rings — הפעלה על Raspberry Pi (איפה שהלדים)

ה-Raspberry Pi הזה יושב ליד טבעות ה-LED ומריץ את התוכנה. הוא מתחבר אוטומטית
לכתובת קבועה באינטרנט, וכך המפעיל שולט מרחוק מכל מקום — בלי שום התקנה אצלו.

> דרוש **Raspberry Pi OS (64-bit)** מעודכן, עם חיבור לאינטרנט. אפשר דרך SSH.

## פעם אחת — התקנה והפעלה

1. חלץ את ה-zip שהורדת לתיקייה כלשהי על ה-Pi, למשל:
   ```bash
   mkdir -p ~/led-rings-host && unzip ~/led-rings-host-bundle.zip -d ~/led-rings-host
   cd ~/led-rings-host
   ```
2. **צור את קובץ הטוקן (פעם אחת).** העתק את התבנית והדבק לתוכה את הטוקן שקיבלת (בערוץ מאובטח, בנפרד):
   ```bash
   cp .led-rings-secrets.example .led-rings-secrets
   nano .led-rings-secrets        # הדבק את הטוקן מיד אחרי  TUNNEL_TOKEN=  ושמור (Ctrl-O, Enter, Ctrl-X)
   ```
   בלי הקובץ הזה התוכנה לא תעלה — המנהרה צריכה את הטוקן. הקובץ נשאר מקומי בלבד; הוא לא בגיט.
3. הרץ את ההתקנה:
   ```bash
   bash led-rings-host.sh
   ```
   בפעם הראשונה זה מתקין הכל לבד — Node.js, cloudflared, הקוד והתלויות — ובונה את
   הממשק (כמה דקות; יבקש סיסמת sudo). בסוף יופיע מסך ירוק, ומאותו רגע התוכנה חיה ב:
   ```
   https://leds.iddofroom.co.il
   ```
   זה רץ ברקע — אפשר לסגור את הטרמינל / להתנתק מ-SSH והוא ממשיך.

*(אופציונלי: זיהוי הביטים — `Detect Beats` — דורש תלויות Python כבדות שההתקנה מנסה
להתקין לבד. אם זה נכשל או נתקע, אפשר Ctrl-C; כל השאר עובד בלעדיו.)*

## שיהיה דלוק תמיד (מומלץ ל-Pi ייעודי)

```bash
bash led-rings-host-enable-autostart.sh
```

פעם אחת — מעכשיו התוכנה עולה לבד בכל הדלקה של ה-Pi (שירות systemd), ומתאוששת לבד
אם היא קורסת. אין צורך להתחבר ולהריץ כלום.

- סטטוס: `systemctl status led-rings-host.service`
- לוגים חיים: `journalctl -u led-rings-host.service -f`
- לעצור עכשיו: `bash led-rings-host-stop.sh` (ולכבות גם את האתחול: `bash led-rings-host-stop.sh --disable`)

## כתובות החומרה

אם שירותי ה-LED של Kivsee רצים על **מכשיר אחר** ברשת (לא ה-Pi הזה) — ערוך את הקובץ
`.env` (נוצר בתוך תיקיית `led-rings`) והחלף `127.0.0.1` ב-IP המקומי של אותו מכשיר.
אם הכל על ה-Pi הזה — אין מה לשנות.

## חשוב לשמור

הטוקן הסודי של המנהרה נמצא **רק** בקובץ `.led-rings-secrets` (שיצרת בשלב 2). אל תשתף אותו,
אל תעלה אותו לגיט, ואל תשלח אותו בקבוצה או מייל פומביים. שאר הקבצים בתיקייה הם קוד רגיל — מותר לשתף אותם.
